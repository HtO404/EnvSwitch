# 快速上手

## 三步

1. **解压**（放哪都行；建议放在目标程序**同一个盘**，例如 `D:\Tools\`）
2. **双击 `EnvSwitch.exe`** —— 提示「未知发布者」时点【更多信息】→【仍要运行】（未签名小工具，免安装）
3. 它会**自动找到**目标程序并填好目录与项目版本；选好环境与版本后点【启动】

## 它帮你省掉了什么

原本切环境要手工改 `appsettings.json`（线上 ↔ 本地、改 ProjectName），容易改错；
现在一个窗口点一下即可，而且**只改 3 个值，其余字节一个不动**（写完回读校验，不符就还原）。

## 工作流按钮

| 按钮 | 干什么 |
|---|---|
| ① 客户端 · 线上 | 拉取基准数据 |
| ② 客户端 · 本地 | 核对拉到的数据 |
| ③ 管理端 · 本地 | 改参数 / 录枚举 |
| ④ 管理端 · 线上 | 保存 → 提交 |

**单击** = 选中（出现主题色「当前」标记）；**双击** = 按这一步启动。右侧【启动】= 按当前选中项启动（单击）。

## 没自动找到怎么办

1. 点【重扫】
2. 或点【浏览】手动指定「管理端」目录
3. 或把本工具解压到它们旁边（同一文件夹 / 同一盘）再点【重扫】

## 出问题怎么找人帮

点右下角【导出诊断】→ 生成 `诊断信息.txt`（含配置、目标程序配置、识别结果、服务与端口状态、最近运行记录）。
把它连同 `运行记录.log` 一起发回即可定位。

## 常见提示

| 现象 | 说明 |
|---|---|
| 状态条「本地服务」红块 | 本机没装对应的本地服务 ⇒「本地」用不了，改用「线上」或找系统管理员 |
| 杀软 / SmartScreen 拦截 | 免安装小工具，加信任即可；也可用 zip 内附带的 `启动EnvSwitch.cmd` |
| 想换回某个环境 | 窗口里选好再点启动，配置会自动写回去，不用手工编辑 |
